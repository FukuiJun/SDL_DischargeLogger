## 1. デザインの方針

- SDL1020X-E 本体の配色に合わせる: **灰色の筐体 + 黒い液晶 + 黄色の数値 + オレンジの区切り線**。
- 画面左の「液晶パネル」に測定値とグラフ、右の「試験条件パネル」に入力、上に接続、下に操作ボタン。
- 本体を見ているのと同じ感覚で、離れた位置からでも数値が読めることを優先する。

## 2. 再現レベル

実装ライブラリは SPEC.md の Q-07（現状 tkinter + matplotlib）に従う。tkinter では難しい表現があるため、優先度を次のとおりとする。

| 優先度 | 対象 | 扱い |
|---|---|---|
| 必須 | 4 章の配置・寸法（±8px）、5 章の色、6 章のフォント、8 章の数値書式、7 章の状態ごとの表示 | 見本どおりに再現する |
| 必須 | グラフの配色（黒背景・黄色の電圧線・青の電流線・オレンジ破線の終止電圧） | matplotlib の rcParams / Axes 設定で再現 |
| 推奨 | セグメント型のラジオボタン（選択中は黒地に黄色文字） | tk.Radiobutton `indicatoron=0` で再現（9 章） |
| 省略可 | 角丸、ボタンの影（下側 2〜3px の濃い線）、液晶まわりの縁取りの角丸 | 四角・影なしでよい |

## 7. 状態ごとの表示

| 状態 | 接続ピル | 接続ボタン / IP・Port | ②-1 状態表示 | ②-2 数値 | グラフ | ③ 入力 | ④ ボタン（有効なもの） |
|---|---|---|---|---|---|---|---|
| 未接続 | 点 `idle` + `未接続` | `接続` / 編集可 | `LOAD OFF` + `未接続`（`lcd-label`） | 全項目 `---`（`lcd-dim`） | 空 | すべて編集可 | なし |
| 待機（接続済み） | 点 `ok` + `接続中` | `切断` / 読み取り専用 | `LOAD OFF` + `待機中`（白） | 電圧・電流・電力は 1 秒ごとに更新、容量・電力量・経過は `---` | 空（前回の結果があれば残す） | すべて編集可 | 放電開始、グラフ保存（データがあるとき） |
| 放電中 | 点 `ok` + `接続中` | `切断` 無効 / 読み取り専用 | `LOAD ON` + `● 放電中`（`lcd-value`） | 全項目を取得周期ごとに更新 | 追記 | 備考のみ編集可、ほかは無効 | 停止・保存、停止・破棄、グラフ保存 |
| 再接続中 | 点 `warn` + `再接続中 (n/10)` | `切断` 無効 | `LOAD ON` + `通信断 — 再接続中`（`lcd-warn`） | 最後の値のまま `lcd-dim` にする | 止める | 放電中と同じ | 停止・保存、停止・破棄 |
| 完了 | 点 `ok` + `接続中` | `切断` / 読み取り専用 | `LOAD OFF` + `完了: <終了理由>`（白）。終了理由は SPEC の「終止電圧到達 / 手動停止 / 通信断」 | 最終値で止める | 残す | すべて編集可（値は残す） | 放電開始、グラフ保存 |

- `保存予定:` の表示: 待機中は `保存予定: 開始時に決定（YYYYMMDD_HHMMSS_4.1V_pana.csv）` のように、現在の選択から作ったパターンを表示する。放電中は確定したファイル名。完了後は `保存済み: <ファイル名>`（破棄した場合は `破棄しました`）。
- 「放電開始」で前回のグラフと数値をクリアする。

## 8. 表示の書式

| 項目 | 書式 | 例 |
|---|---|---|
| 電圧 | 小数 3 桁 + ` V` | `3.491 V` |
| 電流 | 小数 3 桁 + ` A` | `1.000 A` |
| 電力 | 10 W 未満は小数 3 桁、100 W 未満は 2 桁、それ以上は 1 桁 + ` W` | `3.491 W` / `12.35 W` |
| 放電容量 | 小数 1 桁 + ` mAh` | `2209.7 mAh` |
| 電力量 | 小数 3 桁 + ` Wh` | `8.371 Wh` |
| 経過時間 | `HH:MM:SS`（100 時間以上は時の桁を増やす） | `02:12:35` |
| 未取得 | `---` | — |
| メッセージ | `HH:MM:SS <内容>`。色は通常 `text-sub`、警告 `#8a5300`、エラー `danger` | `14:30:05 放電開始（1.000 A / 終止 3.000 V）` |

メッセージの文言（例）:
- 開始: `放電開始（<電流> A / 終止 <終止電圧> V）`
- 自動停止: `終止電圧に到達しました。保存しました: <CSVのフルパス>`
- 手動停止: `停止しました。保存しました: <CSVのフルパス>`
- 破棄: `停止しました。データは破棄しました`
- グラフ保存: `グラフを保存しました: <PNGのフルパス>`
- エラー文言は SPEC.md 9 章に従う

## 9. 部品の作り方（tkinter の場合の指針）

| 部品 | 指針 |
|---|---|
| 色を指定するボタン・ラベル | `ttk` ではなく `tk` のウィジェットを使う（Windows の ttk はボタンの背景色を無視するため） |
| セグメント型ラジオ | `tk.Radiobutton(indicatoron=0, selectcolor=bezel, bg=key, relief="flat", bd=1)`。選択中の文字色（黄）は変数の `trace_add` で `fg` を切り替える |
| 無効表示 | `state="disabled"` + `disabledforeground=text-disabled`。入力欄は `readonlybackground` / `disabledbackground` を `input-bg` に |
| 液晶パネル | 背景 `lcd-bg` の Frame。区切り線は高さ 1px の Frame（`lcd-rule`） |
| グラフ | matplotlib の Figure を `FigureCanvasTkAgg` で液晶 Frame に埋め込む。電圧・電流は 2 段の Axes で横軸を共有（`sharex=True`）。高さ比はおよそ 2:1 |
