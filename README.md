# SDL放電ロガー

Siglent 電子負荷 **SDL1020X-E** を LAN（TCP ソケット）で操作して、リチウムイオン電池の CC 放電試験を記録する Windows 用アプリです（実行ファイル・ウィンドウの名前は `SDL_DischargeLogger`）。

- 電圧・電流・電力を一定周期で取得してグラフにリアルタイム表示
- 放電容量（mAh）・電力量（Wh）を積算
- 終止電圧に達したら負荷を OFF にして自動で停止・保存（CSV と PNG）
- 試験条件（メーカー・満充電電圧・型番・備考）をファイル名と CSV に記録

仕様は [SPEC.md](SPEC.md)、画面デザインは [docs/design/DESIGN.md](docs/design/DESIGN.md)（案A「本体カラー」）を参照してください。

![放電中の画面](docs/design/design_A_running.png)

## 導入

`SDL_DischargeLogger.exe` を好きなフォルダ（例：`C:\Tools\SDL_DischargeLogger\`）に置いてダブルクリックで起動します。
Python や NI-VISA などのドライバのインストールは不要です。

- 設定ファイル `sdl_logger_settings.json` とログ `sdl_logger.log` は **exe と同じフォルダ** に作られます。
  書き込みできるフォルダ（`C:\Program Files` 以外）に置いてください。
- exe は GitHub のリポジトリ画面右側の **Releases** から最新版を開き、`SDL_DischargeLogger-vX.Y.Z.zip` をダウンロードします
  （zip の中に `SDL_DischargeLogger.exe` と README。同じ場所の「Source code」はソースコードで、exe は入っていません）。
  リリース前の最新ビルドは **Actions** → 「Build SDL_DischargeLogger.exe」→ **Artifacts** の `SDL_DischargeLogger` にあります。

## ネットワーク設定（PC と SDL を LAN ケーブルで直結）

| 機器 | IP アドレス | サブネットマスク | ゲートウェイ |
|---|---|---|---|
| PC | 192.168.10.1 | 255.255.255.0 | （空欄） |
| SDL1020X-E | 192.168.10.2 | 255.255.255.0 | （空欄） |

**PC 側（Windows 11）**
1. 設定 →「ネットワークとインターネット」→「イーサネット」を開く
2. 「IP 割り当て」の［編集］→「手動」→ IPv4 をオン
3. IP アドレス `192.168.10.1`、サブネットマスク `255.255.255.0` を入れて保存（ゲートウェイ・DNS は空欄）

**SDL 側**
1. 本体の Utility から LAN（IO 設定）の画面を開く（メニュー名はファームウェアの版で多少異なります）
2. DHCP を OFF にし、IP `192.168.10.2`、サブネットマスク `255.255.255.0` を設定

ポートは SCPI の 5025 番（固定）です。つながらないときは、LAN ケーブル・IP の設定のほか、
Windows のファイアウォール／セキュリティソフトが通信を止めていないかも確認してください。

## 使い方

1. PC と SDL を LAN ケーブルで直結し、`SDL_DischargeLogger.exe` を起動する
2. ［接続］を押す（IP・ポートは前回値）。右上が「● 接続中」になり、メッセージ欄に IDN（`Siglent Technologies,SDL1020X-E,…`）が出ます。
   放電前でも電圧・電流・電力が 1 秒ごとに表示されます
3. 必要ならメーカー・満充電電圧を選び（不明なら「未選択」のまま）、型番・備考を入力する（いずれも任意）
4. 放電電流・終止電圧・取得周期・保存先を確認して［ON/OFF］（放電が始まり、キーの外枠と文字が黄緑に光ります）
5. グラフを見ながら待つ（備考は放電中も編集できます。保存した時点の内容が CSV に入ります）
6. 終止電圧に到達すると自動で負荷 OFF・保存され、ダイアログでお知らせします。
   途中でやめるときは［ON/OFF］をもう一度押します（負荷 OFF）。この時点ではまだ保存されないので、
   ［CSV保存］で CSV とグラフ画像（PNG）を保存します。保存しないまま次の放電を始める・切断する・終了するときは
   「保存していないデータがあります」と確認が出ます（破棄すると一時ファイルも消えます）
7. ［CSV保存］は、自動保存のあとや一度保存したあとも何度でも押せます。上書きはせず、
   `<ベース名>_2.csv`, `_3.csv` …（PNG も同じ名前）として、押した時点の備考で保存し直します

| 画面の項目 | 内容 |
|---|---|
| メーカー | 未選択 / Panasonic / マクセル。起動時は未選択（前回値は引き継ぎません） |
| 満充電電圧 | 未選択 / 4.1V / 4.2V。起動時は未選択（前回値は引き継ぎません） |
| 型番 | 任意、最大 40 文字。起動時は空欄 |
| 放電電流[A] | 0.001〜5.000。初めて起動したときは 0.400（以後は前回値）。5A 以下なので常に 5A レンジを使います。**2.000 A 以上**のときは開始前に確認が出ます |
| 終止電圧[V] | 2.000〜4.200。初めて起動したときは 3.500（以後は前回値）。この電圧以下が **連続 3 回** 続いたら停止。**3.000 V 以下**のときは開始前に確認が出ます |
| 取得周期[s] | 0.2〜60（既定 1.0） |
| 保存先 | ［参照］で選択。初めて起動したときは exe と同じフォルダ（以後は前回値） |
| 備考 | 複数行・カンマ可。放電中も編集可 |
| ☑ 測定中は画面を消さない・ロックしない | 放電中（再接続中を含む）だけ、操作がないことによる画面オフ・ロック・スリープを止めます。手動のスリープ・カバーを閉じたときのスリープ・Win+L のロックは止められません。放電中も切り替えられます |
| ☑ 放電が終わったら音で知らせる | 終止電圧で完了したら上がっていく 3 音、通信断・エラーで止まったら低い 2 音を、ダイアログを閉じるまで約 3 秒おきに鳴らします（最長 10 分）。画面ロック中も鳴ります（スリープ中は鳴りません）。［ON/OFF］で止めたときは鳴らしません |
| ☑ Von を自動設定 | 放電開始時に SDL の Von を「終止電圧 − 0.1 V」、Von Latch を OFF にします。PC が止まっても、電池電圧が Von を下回ったところで SDL 自身が電流を止めるための安全策です。終わって負荷 OFF にしたら元の Von・Latch に戻します。設定できなければ開始しません（チェックを外すと Von なしで開始できます）。放電中は変えられません |

3 つのオプションは初期値がすべて ON で、選んだ状態は次回も引き継ぎます。
| ［CSV保存］ | 負荷 OFF のあと CSV と PNG を保存。何度でも押せて、2 回目からは `<ベース名>_2.csv` … |
| ［グラフ保存］ | ［ON/OFF］で負荷を OFF にしたあと、表示中のグラフを出力フォルダに PNG 保存（`<ベース名>_<時刻>.png`）。放電中は押せません |

放電中はメーカー・満充電電圧・型番・放電電流・終止電圧・取得周期・保存先・接続は変更できません。
放電中にウィンドウを閉じると「放電中です。停止・保存して終了しますか？」と聞かれます
（**はい** = 保存して終了、**いいえ** = 破棄して終了、**キャンセル** = 放電を続ける）。

### 画面の見かた

| 場所 | 内容 |
|---|---|
| 上の接続バー | IP・Port・［接続］/［切断］と接続状態（● 未接続 / 接続中 / 再接続中 (n/10) / 応答なし） |
| 左の液晶パネル | 1 行目：`CC`・`LOAD ON`/`LOAD OFF`・状態（待機中 / ● 放電中 / 通信断 — 再接続中 / 完了: 終了理由）と保存予定のファイル名。<br>数値：電圧・電流・電力（上段）、放電容量・電力量・経過時間（下段）。未取得は `---`、再接続中は最後の値を淡色で表示。<br>グラフ：上が電圧（オレンジの破線が終止電圧）、下が電流。横軸は経過時間（`H:MM`）。<br>下のチップ：電流・終止電圧・取得周期・満充電・メーカー |
| 右の試験条件パネル | メーカー・満充電電圧（選択中は黒地に黄色）、型番・放電電流・終止電圧・取得周期・保存先、備考（青枠＝放電中も編集可） |
| 下の操作バー | ［ON/OFF］（負荷 ON の間はキーの外枠と文字が黄緑に光る）［CSV保存］［グラフ保存］、グラフの［横軸］、最新のメッセージ（時刻つき） |

**グラフの横軸（時間軸）**：操作バーの［横軸］で幅を選べます（測定中も変更可）。「自動」は経過時間に合わせて広がり、
「30分」〜「24時間」を選ぶか「90分」「2.5時間」のように入力すると、その幅で固定します（10分〜100時間）。
経過時間が幅を超えると、最新の値が右端に来るように表示が送られます。保存する PNG は常に全期間です。

Windows の表示倍率（125%・150% など）に合わせて、画面をぼやけずに大きく表示します（画面に収まらない場合は収まる大きさまで）。

［ON/OFF］で放電を始めると前回のグラフと数値は消えます。完了後も入力した条件・型番・備考は残ります（同じ電池で続けて試験できるように）。

### 出力されるファイル

放電 1 回分のファイルは、保存先の中に作るフォルダ `<放電開始日時 YYYYMMDD_HHMM>_SDL` にまとめて出力します
（例: `20261001_1430_SDL`）。同名のフォルダがあるとき（同じ分に開始したときなど）は `20261001_1430_SDL_2`, `_3` … になります。
保存しないで破棄したときは、空になったフォルダも消します。

```
保存先\
└─ 20261001_1430_SDL\
   ├─ 20261001_1430_4v1_pana.csv
   ├─ 20261001_1430_4v1_pana.png
   └─ 20261001_1430_4v1_pana_2.csv など（［CSV保存］をくり返したとき）
```

ベース名は `<放電開始日時 YYYYMMDD_HHMM>[_<満充電電圧>][_<メーカー略称>]` です（未選択の部分は `_` ごと省きます）。
後で扱いやすいように、ファイル名にはドットや大文字を使いません（満充電電圧は 4.1V → `4v1`、4.2V → `4v2`）。

| 満充電電圧 | メーカー | ベース名 |
|---|---|---|
| 4.1V | Panasonic | `20261001_1430_4v1_pana` |
| 4.2V | マクセル | `20261001_1430_4v2_maxell` |
| 未選択 | Panasonic | `20261001_1430_pana` |
| 4.1V | 未選択 | `20261001_1430_4v1` |
| 未選択 | 未選択 | `20261001_1430` |

フォルダの中に同名のファイルがあるとき（［CSV保存］をくり返したとき）は末尾に `_2`, `_3` … が付きます。

| ファイル | 内容 |
|---|---|
| `<ベース名>.csv` | 試験情報ブロック＋測定行（UTF-8 BOM 付き・CRLF。Excel でそのまま開けます） |
| `<ベース名>.png` | 終了時のグラフ（1600×1000 px、資料に貼りやすい白背景。タイトルにベース名・型番・放電電流・終止電圧・結果） |
| `<ベース名>_partial.csv` | 放電中の一時ファイル（1 行ごとに書き込み）。正常に保存されると消えます |

CSV の例:

```
試験情報
開始日時,2026/10/01 14:30
終了日時,2026/10/01 17:12
終了理由,終止電圧到達
メーカー,Panasonic
満充電電圧[V],4.1
型番,NCR18650B
放電電流[A],1.000
終止電圧[V],3.000
放電容量[mAh],2702.5
電力量[Wh],9.874
取得周期[s],1.0
機器,"Siglent Technologies,SDL1020X-E,..."
備考,"25℃恒温槽内。2回目"

日時,経過時間[s],電圧[V],電流[A],電力[W],放電容量[mAh],電力量[Wh]
2026/10/01 14:30:05.120,0.000,4.18512,1.0002,4.1859,0.000,0.0000
2026/10/01 14:30:06.121,1.001,4.15020,1.0001,4.1506,0.278,0.0012
```

- 未選択・未入力の項目は値が空欄になります（行は残ります）
- 「機器」は IDN 文字列にカンマが入るため、ダブルクォートで囲んで 1 つのセルにしています
- 終了理由は「終止電圧到達」「手動停止」「通信断」「保存先書き込みエラー」「異常終了」のいずれか

### 異常時の動作

| 状況 | 動作 |
|---|---|
| 接続時に応答なし | 「接続できません。IP アドレスと LAN ケーブルを確認してください」 |
| 開始時の電圧が終止電圧以下 | 開始しません |
| 保存先に書けない・空き容量不足 | 開始しません |
| 放電中に応答なし・切断 | 1 秒間隔で最大 10 回再接続。復帰したら記録を続けます（欠損区間はそのまま）。復帰しなければ負荷 OFF を試み、「通信断」で保存 |
| 再接続できたが負荷が OFF になっていた（SDL の再起動など） | 「通信断」で保存して停止 |
| 数値でない応答 | その周期は記録しません。10 回続いたら「通信断」で保存して停止 |
| 放電中に保存先に書けなくなった | 負荷 OFF・停止してエラー表示 |
| 最終 CSV が作れない（同名ファイルを Excel で開いている等） | 一時ファイルを残し「保存できませんでした。一時ファイル: <パス>」 |
| 負荷 OFF を確認できなかった | **「SDL 本体で負荷を OFF にしてください」と表示**。本体を確認してください |
| 起動時に保存先（とその中の `*_SDL` フォルダ）に `*_partial.csv`（v1.0.5 までは保存先の `*.partial.csv`）がある | 「前回の記録が途中で終了しています: <パス>」と通知（自動処理はしません。一時ファイルは Excel で開けます） |

PC のフリーズ・電源断ではソフトから負荷を止められません。長時間の無人試験では、SDL 本体側の保護設定の併用も検討してください（SPEC Q-01）。

## 開発

Python 3.12 以上（Windows 11）。

```bat
py -3.12 -m pip install -r requirements.txt
py -3.12 src\main.py          :: GUI を起動
py -3.12 -m pytest            :: 自動テスト
```

### シミュレータ（実機なしで動作確認）

```bat
py -3.12 tools\fake_sdl.py --speed 120
```

127.0.0.1:5025 で SDL のふりをする TCP サーバが起動します。アプリの IP を `127.0.0.1` にして接続してください。
`--speed 120` は時間を 120 倍速で進めます（3000mAh を 1A で放電すると約 1.5 分で終止電圧に達します）。
`--capacity`（mAh）、`--soc`（開始時の充電状態 0〜1）、`--noise`（電圧ノイズ V）も指定できます。

### CLI（GUI なし）

```bat
py -3.12 src\cli.py --host 127.0.0.1 --current 1.0 --cutoff 3.0 --folder out --maker Panasonic --full 4.1V --model NCR18650B
```

### 使っている SCPI コマンド

| 目的 | コマンド | 確認状況 |
|---|---|---|
| 機器確認 | `*IDN?` | 実機確認済み |
| 測定 | `MEAS:VOLT?` / `MEAS:CURR?` / `MEAS:POW?` | 実機確認済み |
| CC モード | `:SOUR:FUNC CURR` | **実機で要確認**（SPEC Q-02） |
| 電流レンジ | `:SOUR:CURR:IRANG 5` | **実機で要確認** |
| 電流設定 | `:SOUR:CURR:LEV:IMM <A>` | **実機で要確認** |
| 負荷 ON/OFF | `:SOUR:INP:STAT ON` / `OFF` | **実機で要確認** |
| 負荷状態 | `:SOUR:INP:STAT?`（`1`/`0` または `ON`/`OFF`） | **実機で要確認**。開始時と停止時に、負荷が本当に ON/OFF になったかの確認に使います |
| Von | `:SOUR:VOLT:LEV:ON <V>` / `:SOUR:VOLT:LEV:ON?` | **実機で要確認**。［Von を自動設定］のとき使います |
| Von Latch | `:SOUR:VOLT:LATC:STAT OFF` / `?` | **実機で要確認**。同上 |

コマンドが違っていた場合は `src/sdl_client.py` の `setup_cc` / `set_load` / `load_state` / `set_von` / `von_settings` を直してください。

## ビルド（exe の作成）

Windows 11 で `build.bat` をダブルクリックします（Python 3.12 が必要）。
パッケージのインストール → テスト → PyInstaller の順に実行し、`dist\SDL_DischargeLogger.exe`（単一ファイル）ができます。

GitHub に push すると、GitHub Actions（Windows）でも同じビルドと起動確認（起動時間の測定）が行われ、
exe が Artifacts に保存されます。

### リリース

1. `src/main.py` の `VERSION` を新しいバージョン（例 `1.1.0`）にしてコミット・push
2. GitHub の **Actions** →「Build SDL_DischargeLogger.exe」→ **Run workflow** で、`release_version` に同じバージョンを入れて実行
   （または `v1.1.0` のタグを push）
3. ビルド・テスト・起動確認が通ると、Releases に `SDL_DischargeLogger-v1.1.0.zip` が載ります
   （タグと `VERSION` が一致しないときは失敗します）
